About

I'm Thomas Saulou, a software engineer interested in what happens when AI agents become real teammates.

This blog is a notebook for ideas about meta-engineering: the practice of building feedback loops, evaluation harnesses, and knowledge systems that let autonomous agents do the implementation work while humans design what "correct" means.

My writing covers AI agents, eval-driven development, LLM tooling, and the shift from writing code to designing the systems that produce code.

Topics

  • Meta-engineering and agent feedback loops
  • Eval-driven development
  • Knowledge codification for autonomous systems
  • Practical AI agent tooling (MCP, structured outputs, tool calling)
